Logo & Wordmark

The mark is an architectural glasshouse frame with a hanging chandelier and flanking botanical leaves – encoding the brand’s three core elements: structure (the frame), elegance (the chandelier), nature (the leaves). This geometry is locked and may never be redrawn for stylistic reasons.

Logo variants

Emerald / light BG
Gold+Sage / dark BG
Bark / print & mono
Ivory / reversed

Misuse

Never mirror or flip
Never rotate
Never recolour outside system
Never on busy photo without overlay
Never add drop-shadow
Never stretch or distort

Clear space & minimum size

Maintain a minimum clear space of 1× the cap-height of the “E” in “Emerald” on all four sides. Minimum display size: 120px wide (full-detail), 40px wide (simplified), 16px (favicon only, not accompanied by wordmark).

Two typefaces. Playfair Display for all headings (warmth, range, proper lowercase). Montserrat for all body and UI copy (clean, legible, pairs well with the serif). No third typeface, ever.

Spacing & Grid

Base-4 scale, stored as CSS custom properties. One container. Two hard breakpoints (mobile 560px, tablet/desktop 900px). No others invented ad-hoc.

TokenValueUse
--space-2xs8pxIcon gap, tight UI spacing
--space-xs12pxBadge padding, form gap
--space-sm16pxParagraph margin, button padding
--space-md24pxCard padding, section sub-spacing
--space-lg40pxCard grid gap, section sub-head gap
--space-xl64pxLarge content gaps
--space-2xl96pxSection padding (mobile)
--space-3xl140pxSection padding (desktop)

Corner radius: Buttons 999px (pill). Cards 18px. Large panels 32px. Organic/blob: CSS border-radius percentage formula. Never sharp (0px) – the brand is warm, not engineered.

Container: max-width 1200px, 24px inline padding. Narrow variant 760px for long-form text (Policies, Brand Design System).

06

Photography & Imagery

All current photos are placeholders. Real photography is a pre-launch requirement.

Approved subjects & mood

  • The actual space, styled for each segment: weddings, corporate, creator, community, wellness
  • Real events in progress – candid, warm, genuine
  • Detail shots: lighting, textures, table settings, the chandelier, the entrance
  • Natural light where possible; warm artificial light acceptable for evening events

Rejected

  • Generic stock photography – especially staged “diverse team laughing” imagery
  • AI-generated photo-real images (allowed for mood boards; never on the live site)
  • Over-saturated or heavily filtered photos that don’t match the actual space
  • Photography of other venues or locations presented as Emerald Grove

Placeholder status

All placeholder images are sourced from picsum.photos with unique seeds – visible “Placeholder photo” labels on every image. All labels must be removed before any photography goes live.

Motion & Animation

One easing curve. Three durations. No exceptions.

TokenValueUse
--easecubic-bezier(0.22, 0.61, 0.36, 1)All transitions – smooth, slightly decelerated
--dur-fast0.2sHover states, button/link transitions
--dur-base0.4sComponent reveals, nav open/close
Scroll reveal0.6s opacity + translateY(18px), stagger 70msSection content on scroll entry

prefers-reduced-motion: Every animated element shows its end-state immediately when reduced motion is active. This is non-negotiable – verified in main.js on page load.

Never use: bounce/spring/elastic easing, autoplay audio, parallax that causes layout shift, any UI transition over 0.5s.

Forms & Inputs

Minimal fields. No dark-pattern required-asterisk tricks – required fields are clearly labeled and validated with native browser constraints plus a phone pattern. Honeypot field on every form (hidden, tabindex -1). Never a visible CAPTCHA.

Backend: Google Apps Script web app (POST, no-cors) → Google Sheet log → owner email alert → customer confirmation. Endpoint URL lives in config.js formEndpoint.

17

Do’s & Don’ts

The fastest onboarding checklist for any new collaborator. Eight rule pairs.

✓ Do

Use only the five locked palette colours – Emerald, Forest, Sage, Sand, Gold – via CSS custom properties.

Token discipline is what keeps the brand coherent across every surface and every contributor.
✕ Don’t

Introduce a third typeface, a blue link colour, a green success state, or any hex not in the token block.

One unexpected colour breaks the "five colours" law permanently in that viewer's eyes.
✓ Do

Set every heading in Playfair Display, every UI and body element in Montserrat.

The serif+sans pairing is the most visible carrier of the brand's warmth-with-precision character.
✕ Don’t

Use Inter, Roboto, Poppins or any system sans-serif as a brand typeface.

These are the defaults that make everything look the same. They actively destroy differentiation.
✓ Do

Use the logo mark as an inline SVG in the header/footer, rendered by components.js from the locked geometry.

The mark is locked geometry – component injection means it can never accidentally drift from the source of truth.
✕ Don’t

Redraw, mirror, rotate, stretch, recolour, shadow, or crop the logo mark for any reason.

The mark encodes structure + elegance + nature. Any modification destroys that encoded meaning.
✓ Do

One primary CTA per view. Name it with an action verb: “Enquire now”, “See the space”, “Send another enquiry”.

Multiple CTAs split attention and dilute conversion; the right verb tells people exactly what happens next.
✕ Don’t

Use “Click here”, “Submit”, “Learn more”, all-caps labels, or exclamation marks on any button.

Generic labels are invisible. Vague labels create anxiety. Shouting labels are off-brand.
✓ Do

Update config.js when any contact detail, social link or brand copy changes – and nothing else.

Config is the single source of truth for identity. Change it once and every page updates instantly.
✕ Don’t

Hardcode phone numbers, email addresses, or the brand name inside individual HTML files.

Hardcoded values go stale and diverge. When the phone number changes, you can’t find them all.
✓ Do

Every animation respects prefers-reduced-motion by showing the end state immediately – verified in main.js.

Motion sickness is real. This is a legal accessibility requirement in many markets and a human decency baseline in all of them.
✕ Don’t

Use bounce, spring or elastic easing. Use autoplay audio. Add UI transitions over 0.5s. Add parallax that shifts layout.

These slow pages down, cause nausea for some users, and feel inconsistent with the calm, premium brand character.
✓ Do

Use only real photography of the actual space for the live site, with explicit written consent for any identifiable person.

A venue brand lives or dies on its photography. AI images, stock images and other-venue images all erode trust the moment someone shows up in person.
✕ Don’t

Launch with placeholder images from picsum.photos. Label them clearly in development; remove all labels before going live.

Placeholder labels are a development convention, not a design feature.
✓ Do

Keep pricing off the public pages. Share pricing.html by direct URL after an enquiry, where context and relationship exist.

Enquiry-gated pricing lets you flex on discounts, bundle add-ons, and read the customer before quoting. Numbers without context create rejection before conversation.
✕ Don’t

Add pricing.html to the nav, link it from any public page, or add a sitemap entry for it.

The page already carries noindex and a robots.txt Disallow. Any public link defeats both protections at once.

  • All placeholder photos replaced with real venue photography
  • “Placeholder photo” labels removed from every image
  • config.js: formEndpoint updated to live Apps Script URL
  • config.js: YouTube and Facebook URLs updated (not “#”)
  • policies.html: draft banner removed (post legal review)
  • policies.html: registered entity name + address filled in
  • apps-script-Code.gs: OWNER_EMAILS confirmed correct; redeployed as new version

  • Domain DNS: GoDaddy pointed correctly at Cloudflare Pages
  • Contact page map: mapsEmbedSrc and mapsUrl updated to exact venue coordinates

  • Browser tab favicon verified at 16px and 32px
